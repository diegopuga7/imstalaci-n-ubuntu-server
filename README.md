# imstalaci-n-ubuntu-server
VirualBox
1. Primer paso:
Tenemos que instalar la ISO de ubuntu

2. Segundo paso:
Abrir VirtualBox y darle a nueva (esto es para añadir una nueva maquina virtual)

3. Tercer paso:
Tenemos que subir la ISO en su respectivo apartado,despues tenemos que activar la opción de "Proceed with Unattended Installation"

4. Cuarto paso:
tenemos que ajustar la RAM y el almacenamiento, yo he subido los nucleos del procesador a 2 y el almacenamiento lo he dejado por defecto que vien en 25gb, luego le das a "Finalizar" y ya se crea la maquina virtual
